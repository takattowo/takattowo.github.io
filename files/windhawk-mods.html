Windhawk mods

A list of Winhawk mods I made to imrpove the Windows QOL.

Expanded Clipboard (Win+V) - Raises the 25 item cap of Windows clipboard history and lifts the per-item / total buffer size limit so large images stick.

Start Menu Search Engine Swap - Replaces Bing with your chosen search engine (Google, DuckDuckGo, etc.) when clicking web results in Start menu search. Also strips the microsoft-edge: protocol so the URL opens in your default browser.
