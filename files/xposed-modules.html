Xposed modules

A list of Xposed modules I made during free time.

OutlookDevicePolicyBypass (Github / LSPosed) - Kills the MDM device-policy enrollment prompt in Microsoft Outlook for Android (com.microsoft.office.outlook) so you can use Outlook on Android without having to set Outlook as Device Admin.

BootloaderSpoofer (Github / LSPosed) - Modify certificate extension to bypass hardware integrity local attestations. Ships with the public Google Android Software Attestation Root test keybox (the same EC + RSA keys/certs every prior fork embeds). These are public, not TEE-backed, and will not beat any online check that validates against Google's hardware attestation root or revocation list. Local attestation only.
